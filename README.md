# TR Games Hub

TR Gaming Nest — the games portfolio of Thinking Reimagined.

**Mission:** Amplify human judgment while preserving human agency.

Players enter because the game is enjoyable, continue because the decisions are compelling, and leave with stronger judgment through consequences, patterns and revised strategies.

## Current focus

**One More Shift — Festival Finish** is the lead prototype. It is in pre-production; this repository does not yet contain a playable game.

The first build will include 18 crew, three linked operating areas, a machine failure and a late rush in a six-minute strategy scenario, with tactical pause and instant rematch.

## Development sequence

1. Implement and verify the deterministic simulation.
2. Build the visible, interactive workshop board.
3. Finish a complete playable shift and rematch.
4. Observe player clarity, strategy variety and voluntary replay before expanding.

Only one game is in active development at a time. Trash Panda Heist and Payday to Payday are secondary opportunities; remaining concepts stay as structured briefs.

## Boundaries

Human choice remains central. Learning emerges through play. Difficulty rewards growing judgment, and monetization must respect players' attention and agency.

Runway, breathing apps and SPY research remain separate projects.
