# Development roadmap

## 8. Phased development roadmap
One active game build at a time. Effort ranges below are rough focused maker-days, not promises or calendar commitments; art, iteration and tooling experience can materially change them.

| Phase | Scope/output | Gate | Indicative effort |
|---|---|---|---|
| 0 — pre-production | This portfolio screen and frozen Festival Finish build contract | Lead and alternatives explicit; no blocking design decision | Completed document |
| 1 — simulation proof | Deterministic three-stage flow, 18 crew, energy/travel, failure, rush; run several scripted policies | Conservation/replay checks pass; at least two viable base strategies; full rush not trivially dominant | 1–3 days |
| 2 — playable board | Selection, visible flow, feedback, deadlines, pause, rematch and result card | Entire six-minute run playable without facilitator; every action legible | 3–6 days |
| 3 — fun test and revision | Observe 8–12 players; make one focused revision and retest the changed problem | Replay/clarity targets and strategy variety met, or documented pivot | 2–4 days plus recruitment |
| 4 — vertical slice | Three shifts, coherent original art/audio, accessibility pass, authored progression | Players want more scenarios; production scope and cost now estimable | Estimate after phase 3 |
| 5 — release decision | Public demo test, packaging, title/legal asset checks, support plan and paid-game offer hypothesis | Audience evidence and sustainable production case; no assumed revenue | Estimate after slice |
| 6 — second portfolio proof | Prototype either Trash Panda Heist for entertainment breadth or Payday for Runway connection | Choose using observed audience response and capacity; extract reusable code only where proven | Deferred |

Incubation questions: Fix the Fix—can testing a causal hypothesis feel like repairing something delightful? Proof Positive—can changing one's mind create a satisfying mystery reveal? Make the Hit—can arranging original stems feel creative without needing a full music workstation? Use paper/audio sketches only if a specific decision needs evidence; otherwise keep them dormant during the lead build.
